# PC EVENTOS - Anotador de Fechas DJ 🎧

Anotador y calendario de fechas estilo Google Calendar desarrollado a medida para la empresa DJ **PC EVENTOS**. Diseñado con tema oscuro (Dark Mode), tipografía en blanco nítido y resaltado de fechas reservadas en **verde fluo (`#00ff66`)**.

## 🌟 Características Principales

- **Tema Oscuro & Verde Fluo**: Fondos negros profundos con tipografía en blanco puro y fechas reservadas que se iluminan en verde fluo (`#00ff66`) mostrando el nombre del evento.
- **Logo Oficial de PC EVENTOS**: Monograma vectorial integrado en cabecera y modales.
- **Calendario Estilo Google Calendar**:
  - Vista **Mes**, Vista **Semana** y Vista **Agenda** cronológica.
  - Navegación rápida: Anterior, Siguiente, Hoy y selector desplegable para saltar a **cualquier mes y año**.
- **Gestión Completa de Eventos DJ**:
  - Nombre del evento (Casamientos, Fiestas de 15, Cumpleaños, Boliches, Corporativos).
  - Horarios de inicio y finalización.
  - Salón / Quinta / Locación y dirección.
  - Datos del cliente y teléfono con enlace directo a WhatsApp.
  - DJ asignado del staff.
  - Checklist de rider técnico (Cabina Pioneer, Sonido Line Array, Cabezas móviles, Láser RGB, Pantalla LED, etc.).
  - Estados: *Confirmado*, *Señado (En Reserva)* o *En Consulta*.
  - Presupuesto total, seña abonada y saldo restante.
- **Compartir por WhatsApp**: Genera automáticamente la ficha técnica formateada para enviar al cliente o al staff técnico con un solo clic.
- **Persistencia Local**: Guarda todos los eventos en `localStorage` del navegador.

## 🚀 Instalación y Uso Local

### 1. Clonar el repositorio
```bash
git clone https://github.com/TU_USUARIO/pc-eventos-calendar.git
cd pc-eventos-calendar
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Iniciar el servidor de desarrollo
```bash
npm run dev
```

Abre tu navegador en `http://localhost:3000` (o el puerto indicado en la consola).

### 4. Compilar para producción
```bash
npm run build
```
